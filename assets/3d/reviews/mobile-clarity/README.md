# Nitidez e preços no celular

Prévia real do GameScreen com jogo/conexão simulados. Atlas 6K confirmado no navegador móvel; preços de tamanho constante 10,5 px CSS, textura a densidade 4, inclinados na profundidade das propriedades. Dados oficiais derivados pelo GameBoard. Mantida a prioridade dos personagens sobre as etiquetas.

mobile-clarity-qa.mjs: três proporções móveis e desktop, todas as 26 propriedades compradas. O modo CLARITY_CAPTURE_ONLY=1 atualiza capturas/medidas sem repetir interações já conferidas. Relatório final verifica interseção dos polígonos das etiquetas; o cenário usa construção nível 2. Não é uma medição de desempenho em aparelho físico.

Capturas anteriores para comparação em ../mobile-diamond/. Fonte da arte preservada; a melhoria usa o atlas de maior resolução que já existia no projeto.
